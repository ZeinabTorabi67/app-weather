# Weather App

This project was created as part of the Karyar JavaScript Week 0 entrance challenge.

## Project Structure

- `index.html`: Main HTML page
- `css/style.css`: Stylesheet
- `js/app.js`: JavaScript file

## What I Practiced

- Connecting JavaScript to HTML using `defer`
- Displaying messages with `console.log()`
- Inspecting the browser Console
- Testing and debugging JavaScript execution and DOM access
- Using Git and GitHub to manage project changes
